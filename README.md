# Online Bookstore – PostgreSQL SQL Project

## 📌 Project Overview
This project is based on an Online Bookstore database created using PostgreSQL.

The project covers data loading, SQL queries, joins, aggregations, filtering, and business analysis.

## 🛠️ Tools & Technologies
- PostgreSQL
- SQL
- VS Code
- CSV Files

## 📂 Database Tables
- Books
- Customers
- Orders

## 🔍 Key Analysis
The project includes SQL queries for:
- Finding books by genre and publication year
- Analyzing customers by country and city
- Checking orders by date
- Calculating total stock and remaining stock
- Finding expensive and frequently ordered books
- Analyzing sales by author
- Finding highest-spending customers

## 📊 SQL Concepts Used
- SELECT & WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOIN
- DISTINCT
- BETWEEN
- CASE
- COALESCE
- Subqueries
